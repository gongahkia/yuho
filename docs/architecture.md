# Haskell module composition and kernel lowering

Yuho resolves exact local statutory modules before ordinary model checking. A module exports typed declarations; a host explicitly selects declarations and attachments. Import order and `use` order are source order, and final executable identifiers are never silently renamed.

There are two supported module styles:

1. A compatibility view points several manifests at one checked source graph. It preserves the earlier modular fixtures.
2. Independent composition selects definitions, offences, general exceptions and candidate penalties from separate source models. The resolver merges only explicitly used declarations, de-duplicates identical source and quotation identities, rejects inconsistent or colliding identities, constructs the attachment graph, and sends the resulting model through the ordinary checker.

The independent composition boundary is intentionally bounded. Cross-module participation and attempt declarations remain complete specialised submodels rather than declarations merged into a multi-offence host. This keeps the existing strongly typed participation and attempt invariants and the stable KernelInput boundary.

Module names and versions identify authored local content. They do not select the law applicable to conduct on a date. Module metadata is omitted from KernelInput. Equivalent modular and monolithic graphs therefore lower to identical request and response bytes.

Every normal model ultimately lowers to one of the existing kernel boundaries. Multi-allegation cases contain ordered, independent KernelInputs; they do not merge results or derive an aggregate case status. A `presumption-program` wraps one ordinary compiled proof request with registered trigger and rebuttal declarations and uses `RegisteredPresumptionDerivations-v1` as a separately named technical subprogram.

Resolution refuses unsafe paths, missing exact versions, duplicate aliases or identities, cycles, private or wrong-kind access, unresolved references, structural source/quotation conflicts and final legal-identity collisions. The current bounds are 32 modules, 32 case allegations, 16 presumption registrations and 65,536 bytes per local source file.
