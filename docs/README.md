# Yuho documentation

Yuho Haskell Research Language v1.0 has one supported documentation surface:

- [Getting started](getting-started.md): installation and a ten-minute tour.
- [Language reference](language-reference.md): supported `.yh` constructs and examples.
- [CLI reference](cli-reference.md): commands, options, outputs and exit behavior.
- [Architecture](architecture.md): checked frontend, Core, lowering and kernel boundaries.
- [Formal semantics](formal-semantics.md): the current cumulative Core Yuho specification.
- [Mechanisation](mechanisation.md): Lean theorem and Haskell–Lean conformance boundaries.
- [Diagrams](diagrams.md): native semantic-graph JSON and SVG.
- [Singapore corpus](corpus.md): structural inventory and executable research subset.
- [Assurance](assurance.md): proof, testing and legal claim boundaries.
- [Positioning](positioning.md): restrained comparison with related legal systems.
- [Deferred work](roadmap.md): optional research and tooling directions.

The repository root [README](../README.md) gives the shortest product overview. The generated [Singapore corpus index](../research/singapore/CORPUS-INDEX.md), schemas under [`schema/`](../schema/), and proof artifacts under [`mechanisation/`](../mechanisation/) are normative evidence, not separate products.
