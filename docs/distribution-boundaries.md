# Public distribution boundaries awaiting owner selection

The accepted experimental SDK remains technically supported. Distribution
rights must be assessed for the actual contents and each public surface.

| Surface | Present exposure | Effect of an SDK-only archive |
| --- | --- | --- |
| Public GitHub tree | Code, research extracts, four mascots and two external-source indices | No change; archive exclusions do not remove public files |
| Cabal SDK source package | Code, schemas, guides, examples and SDK tests, including legislative wording | An approved narrower package could omit excerpt-dependent examples/tests |
| Complete reproducibility bundle | Full research verification inputs, assets, indices and historical kernel | A smaller SDK cannot reproduce the full research gate |
| Git history and earlier artifacts | Earlier paths, scraper code and previously reachable assets | Unchanged; deletion of current paths does not rewrite history or recall artifacts |

Candidate A retains the comprehensive material set. It requires asset/data
provenance, source/accuracy/acquisition review, applicable quotation permission
or other approved basis, and all required notices. It is not cleared by adding
notices or by a passing test suite.

Candidate B is an inspection proposal: original library modules, public schemas,
pinned build metadata, original technical guidance, licence/notice records and
a wholly synthetic public-facade consumer. Existing excerpt-dependent test and
example files would be omitted from that proposed package, while full research
verification remains unchanged in the original tree. An external temporary
candidate may demonstrate compilation, all admitted profiles, projection and
synthetic source recovery. Its complete allowlist requires review, and the
owner must approve the final boundary before it becomes a release artifact.

No mascot, dataset, quotation or research source was deleted or replaced by
this proposal. Neither public visibility nor an original-software licence proves
rights over external contents. No archive is authorised for publication here.
See [rights notices](third-party-notices.md), [legislation](legislation-notice.md)
and [owner authorisation](owner-authorisation.md). Full verification commands
remain in the [distribution contract](distribution.md).
