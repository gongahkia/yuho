## Extraction and generated packet

The [offline source-specific extractor](../../research/singapore/section-84-pilot/tools/extract_sources.py) uses Python’s standard-library HTML parser. It strictly decodes UTF-8 and HTML entities, selects only the active `div#legis` and exact `div.prov1` IDs, inserts LF before structural rows/list cells, collapses whitespace only inside a structural line, removes blank lines, and preserves subsection/list order. It does not apply NFC/NFKC normalization, change spelling or punctuation, load local assets, execute JavaScript or fetch a URL. Because text is reflowed from HTML, spans refer to **exact extracted UTF-8 bytes**, not offsets in the HTML. The transform is `yuho.sg-legislation-html-extraction/v1`; its [README](../../research/singapore/section-84-pilot/README.md) documents limits and deterministic regeneration.

The eight generated files live only in the external `sg-s84-generated/` directory. The [source lock](../../research/singapore/section-84-pilot/SOURCE-LOCK.json) lists SHA-256 and byte length for **every** file. The three text artifacts are:

## Representability and legal-review boundary

Existing closed Boolean branches can describe the source order and alternatives of s 84(1) and the two s 84(2) clauses **as structure**; exact leaf IDs, supplied proof labels and an exception target can describe a hypothetical technical input. They do not establish the causal “by reason of” link by simply conjoining labels, decide whether the EA s 107 burden was discharged, select the law applicable to an alleged-act date, or turn a defeated branch into an acquittal. CPC ss 246–256C supply separate proceeding context; no fitness or order is evaluated. Penal Code s 323 is not executed or positively scoped. The external scope file explicitly excludes real-person diagnosis, evidence assessment, outcomes, sentence, current-law certification, independent legal review and authenticated provenance.

This packet is **not a valid `ModelBundle-v1`**. That [format](MODEL-BUNDLE-V1.md) requires a complete canonical executable KernelInput artifact and exact semantic-ID inventory; this milestone deliberately creates neither. Conversion requires appropriately reviewed source bytes and transformation fidelity, a confirmed point-in-time expression, qualified review of statutory propositions and cross-instrument effects, an accepted offence/exception boundary if execution is sought, approved executable semantics, and a later review assertion naming the *exact future bundle digest*. A hash matches bytes; it does not authenticate SSO, establish applicability or certify the model.

## Access and redistribution limits

Direct access to [SSO Terms of Use](https://sso.agc.gov.sg/Terms-of-Use) and its [FAQ](https://sso.agc.gov.sg/FAQ) returned HTTP 403 during this pass. The indexed Terms describe proprietary rights, and [AGC’s SSO page](https://www.agc.gov.sg/our-roles/drafter-of-laws/singapore-statutes-online/) directs reproduction questions to the FAQ. Permission for repository redistribution was therefore **not verified**. No full HTML, companion asset, extracted statute text or lengthy statutory reproduction enters Git. This is a conservative handling choice, not a conclusion about copyright. The browser-saved source, page branding, saved URL and hashes do not authenticate publication. The SSO access gap and all statutory/temporal/interpretive questions in the [review packet](SINGAPORE-SECTION-84-LEGAL-REVIEW-PACKET.md) remain open.
