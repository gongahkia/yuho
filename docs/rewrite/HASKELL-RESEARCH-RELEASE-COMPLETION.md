# Research release completion record

Yuho Haskell Research Language v0.1 closes the planned two-pass research-language build. The Haskell frontend now owns modules, composition, temporal selection, offences, exceptions, participation, attempt, supplied facts, cases, penalties, presumption subprograms, lowering, in-process execution and explanations.

The release adds seven independently authored offence modules, four non-s 84 general-exception expressions, 56 substantive decision scenarios, two broader s 511 demonstrations, a non-theft intentional-aid demonstration and two new multi-offence showcase cases. Existing hurt, theft, cheating, mischief, s 84, s 107 and warehouse-case fixtures remain compatibility evidence.

The release is complete in the bounded research sense: the included authored models are discoverable and operable, unsupported legal questions are visible, and no further implementation milestone is required for coherence. Corpus expansion, richer cross-module specialised declarations, more punishment types, editor tooling and additional jurisdictions are optional future work.

## Verified release boundary

The release was built offline with GHC 9.8.4 and the unchanged Cabal freeze file. The complete `foundation-test` passed, including the existing Haskell surface regressions and the new release checks. The seven protocol scripts passed their schema, vector, canonical-byte and persistent-process checks; the supplied-proof suite observed 72 fixtures and 111 persistent requests. All 318 prior response comparisons remained byte-identical to their committed baseline.

The newly built CLI checked, compiled twice, ran and explained all 56 new-family scenarios, three cross-cutting scenarios, three showcase cases, four fictional presumption states and both fictional temporal boundary scenarios. Representative commands also passed from outside the checkout with Python absent from `PATH`. Documentation links, capability-claim boundaries, Git whitespace and the frozen byte hashes passed their release checks.

## Operating boundary

Independent composition currently merges definitions, offences, general exceptions and candidate penalties. Specialised participation and attempt declarations remain whole typed graphs. Registered presumptions execute as an explicitly named separate technical subprogram because the established kernel variants do not combine that derivation with an offence request. These bounded forms, and all optional or deferred work, are classified in the [capability matrix](HASKELL-RESEARCH-RELEASE-v0.1.md).
