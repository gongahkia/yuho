# Reproducibility and correction record

Fixtures were frozen before either candidate at repository HEAD `6f95b1d450b44777c5aa27b16fa61db2c525f824`; [MANIFEST.json](../fixtures/MANIFEST.json) SHA-256 is `fc5c932a370b0efc88be23dbc84c5024211f8fdebbe8c4ec800483e289e3c715`. All 15 request and expected-response files and source files carry individual SHA-256 values in that manifest. B06/B07 source is exactly six bytes `a\nb\nc\n`, SHA-256 `880553fca8fcea94e325ee2cfb48e5a985cc797f39a14cc6d3cedecfeb2ae4d2`. Fixture files were made read-only after freezing and were not edited during candidate work.

The host was Fedora Linux 43, kernel `7.1.12-100.fc43.x86_64`, Intel Core i7-1355U, 12 logical CPUs, 15 GiB RAM and 8 GiB swap. Before measurement, roughly 8.6 GiB RAM was available; large resident GUI/search processes included Baloo (~1.2 GiB) and several Helium processes. Candidates were built and measured serially. A later snapshot showed 8.1 GiB available and 2.9 GiB swap used. These observations supported running the small spike locally, but make the latency numbers host/session-specific. GHC 9.8.4, Cabal 3.10.3.0, OCaml 5.3.0, Python 3.14 and system `jsonschema` 4.26.0 were present; the harness version is pinned in [requirements.txt](../harness/requirements.txt). No compiler, package or system dependency was installed.

From repository root, with the listed toolchains already available:

```sh
YUHO_ANALYSIS_CACHE=0 .venv/bin/python experiments/language-spike/harness/freeze.py  # extraction only; do not rerun after freeze
.venv/bin/python experiments/language-spike/harness/verify_frozen.py
(cd experiments/language-spike/haskell && cabal v2-build --offline --jobs=1)
(cd experiments/language-spike/ocaml && make all)
/usr/bin/python3 experiments/language-spike/harness/run.py
/usr/bin/python3 experiments/language-spike/harness/verify_vectors.py
/usr/bin/python3 experiments/language-spike/harness/package.py
```

The first command documents the original extraction, not a routine check: rerunning it would rewrite frozen fixtures. `verify_frozen.py` is read-only and also checks links and test symbols. `run.py` performs JSON Schema Draft 2020-12 validation, exact structural and byte parity, 100 shuffled-key repetitions per case in 10 fresh processes, 30 cold launches, a 1,000-request steady run, protocol rejection, parser-diagnostic transport, clean-directory replay, and candidate-derived proof-vector export. `verify_vectors.py` reads all seven vectors back for each candidate and checks IDs, paths and every child edge against the frozen response. `package.py` copies each candidate to a clean temporary source directory, builds offline, copies only its executable to another clean directory, and replays B01/P02. Both scored scripts execute Haskell first and OCaml second, never concurrently. [RAW-MEASUREMENTS.json](RAW-MEASUREMENTS.json) has the 30 raw cold samples per candidate; [PACKAGING.json](PACKAGING.json) and the two build logs give package evidence. The trial with `/usr/bin/time`'s zero-valued 10 ms wall-clock samples was invalidated; the final run uses `time.perf_counter_ns` for elapsed time while retaining `/usr/bin/time` for RSS. CPU samples retain 10 ms resolution and are not useful at this workload scale.

The Haskell candidate was implemented, checked 15/15 and frozen first. OCaml was then implemented without modifying Haskell, checked 15/15 and frozen. After both initial versions, one bounded correction pass per candidate fixed Haskell's missing stdout flush for interactive steady-state requests and OCaml's acceptance of invalid raw UTF-8. Both were rebuilt and rerun against all unchanged frozen bytes; [HASKELL-INITIAL.json](HASKELL-INITIAL.json) and [OCAML-INITIAL.json](OCAML-INITIAL.json) record initial and final source/binary hashes and corrections. No additional candidate source correction was made.

One genuine specification/schema defect was found before scored measurement: the initial schema `$id` values were opaque relative identifiers, so the result schema's relative cross-file `$ref` could not resolve as a URL in a Draft 2020-12 validator. Both schema `$id` values and the two cross-file references were changed to stable absolute schema URIs. This changed no request, response, source or manifest byte and no candidate semantics; both candidate runs were invalidated and rerun through the common validator. The [schema explanation](../schema/README.md) and [spike specification](../../../docs/rewrite/LANGUAGE-SPIKE-SPEC.md) record this clarification.

No full Python suite, corpus-wide export, grammar regeneration, Lake build, Docker build, native parser/LSP, proof theorem or production semantics change was run or made. The available checks were the frozen fixture verifier, the common conformance/measurement harness, the clean packaging harness, the repository's documentation capability checker and `git diff --check` (final command outcomes are in the handoff). This bundle does not supply either independent clarity review; its reviewer fields remain open.
