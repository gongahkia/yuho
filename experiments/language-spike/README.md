# Yuho language-neutral semantic-kernel spike

This isolated experiment compares Haskell and OCaml on the same `ClosedBooleanBranches-v1` semantic fragment and one-line JSON protocol. It does not implement a new source language, parser, LSP, solver, legal outcome model, exception fragment or production replacement. The legacy Python adapter in [harness/freeze.py](harness/freeze.py) was used only to project and freeze synthetic migration fixtures; neither scored executable calls Python. Canonical IR v1.2 and its hashes are untouched.

The 15 immutable requests and expected responses are in [fixtures/](fixtures/), with source bytes and SHA-256 in [MANIFEST.json](fixtures/MANIFEST.json). Versioned shape and canonicalization rules are in [schema/](schema/). Both candidates use explicit typed nodes, invariant checks, deterministic sorted-key JSON output and total result handling for scored errors. The [common harness](harness/run.py) and [clean package check](harness/package.py) run Haskell then OCaml serially against the same fixtures. See [REPRODUCIBILITY.md](results/REPRODUCIBILITY.md) for commands and environment.

The [scorecard](results/SCORECARD.md), [Haskell review packet](results/HASKELL-REVIEW-PACKET.md), [OCaml review packet](results/OCAML-REVIEW-PACKET.md) and [native-toolchain risk assessment](results/TOOLCHAIN-RISK-ASSESSMENT.md) are the review bundle. All technical fixture and resource gates passed on the measured host. Two independent clarity reviews and the maintainer's final language decision remain open. ADR-0001 is still provisional.
