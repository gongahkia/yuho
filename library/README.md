# Saved Penal Code corpus

[`penal_code/`](penal_code/) is the saved structural input used to build Yuho’s 524-row Singapore Penal Code coverage inventory. The `_raw/act.json` export and per-provision `statute.yh` quotations are research/source material; they are not accepted as current Haskell executable models merely because they use a `.yh` suffix.

Executable Yuho models, modules, scenarios and cases live under [`research/singapore/`](../research/singapore/). The canonical classification is [`SINGAPORE-CRIMINAL-LAW-COVERAGE-v0.3.json`](../research/singapore/SINGAPORE-CRIMINAL-LAW-COVERAGE-v0.3.json), and the generated human index is [`CORPUS-INDEX.md`](../research/singapore/CORPUS-INDEX.md).

The `_ledger`, `_coverage` and `_L3_review` material is retained research evidence. It does not establish legal currency, comprehensive review or executable support.
