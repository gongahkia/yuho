# Production KernelInput/Result v1 schemas

The separate [ModelBundle-v1 specification](../../../docs/rewrite/MODEL-BUNDLE-V1.md) has closed [core](model-bundle-core.schema.json), [unsigned review](model-bundle-review.schema.json) and [validator result](model-bundle-validation.schema.json) Draft 2020-12 schemas. These are a build/package profile, **not** an eighth alternative in the KernelInput/Result unions below. Schema checks cover local shapes; the Haskell offline validator additionally checks canonical bytes, filesystem types, raw SHA-256/length, all references, exact semantic-ID inventory, source spans, derivation cycles and review applicability. [Synthetic CLI fixtures](../test/model-bundle-fixtures/CASES.json) exercise those checks.

The external [ModelBundleChangeSet-v1](../../../docs/rewrite/MODEL-BUNDLE-CHANGE-IMPACT-PROVISIONAL-SPEC.md) has its own closed [report schema](model-bundle-change-set.schema.json) and [committed CLI snapshots](../test/model-bundle-diff-fixtures/CASES.json). It compares only two independently validated v1 packages, reports deterministic structural rows and review non-transfer, and changes no kernel schema or bundle-core digest. The Haskell stored-report decoder additionally checks canonical bytes, row ordering, counts, digest presence and the one MiB output/readback cap.

[request.schema.json](request.schema.json) and [result.schema.json](result.schema.json) are closed JSON Schema Draft 2020-12 discriminated unions for `ClosedBooleanBranches-v1`, `AcyclicGuardedExceptions-v1`, `TypedBooleanFacts-v1`, `GuardedPenaltySelection-v1`, `PenaltyTerms-v1`, `SuppliedProofStatus-v1` and `RegisteredPresumptionDerivations-v1`. They do not alter the frozen language-spike schemas or Canonical IR v1.2. The previous six wire response variants retain their original bytes.

Schema validation checks wire shape, constructors, field closure and primitive types. It cannot prove globally unique IDs, total facts/status bindings, resolved targets, UTF-8 source/span consistency, real calendar dates, whole-registry acyclicity, expanded occurrence limits, resource-safe stream handling, source-contained term spans, numeric order or semantic trace agreement. The Haskell decoder and validator perform those checks before evaluation. The typed result adds ordered fact observations and `KINV007` binding rejection; the fourth adds selected declaration IDs, ordered supports, per-branch selection trace and `KSEL001` warnings; the fifth adds canonical validated term trees only to selected records. The sixth adds externally supplied status/source records, three-valued technical satisfaction and ordered proof observations; `KINV010` rejects assignment identity/source/span invariants. The seventh adds ordered technical derivations and distinct direct/effective observations; all earlier result variants remain unchanged. Facts and diagnostic parameters are the only dynamic-key maps. JSON Schema string lengths count characters, while the Haskell boundary additionally bounds selected fields by UTF-8 bytes.

Run the [exception protocol check](../test/exception_protocol.py) with the pinned Haskell executable to validate positive requests and every result, including rejections. Invalid requests are intentionally *not* all schema-valid: structural failures are expected to fail the schema, while missing references and cycles can be well-shaped and still fail Haskell model validation. The [normative fragment specification](../../../docs/rewrite/ACYCLIC-GUARDED-EXCEPTIONS-V1.md) defines the semantic layer.

The [typed protocol check](../test/typed_protocol.py) validates the new discriminated request/result shape, 53 synthetic fixtures, ordered observations and persistent rejection recovery. Its [normative specification](../../../docs/rewrite/TYPED-BOOLEAN-FACTS-V1.md) distinguishes Boolean leaf bindings, annotation checks and descriptive provenance from proof status.

The [penalty protocol check](../test/penalty_protocol.py) validates the fourth request/result shape, 49 synthetic GP fixtures, 76 persistent requests, proof-neutral vectors, the 4,096-occurrence boundary, canonical bytes and rejection recovery. Its [normative specification](../../../docs/rewrite/GUARDED-PENALTY-SELECTION-V1.md) defines exact trace-based guard scope, candidate ID selection and path-specific overlap warnings. Raw malformed JSON may not reveal a fragment before dispatch and retains the generic pre-dispatch rejection envelope.

The [term protocol check](../test/terms_protocol.py) validates the fifth closed shape, all 68 PT fixtures, 110 persistent requests, complete result schemas, proof-neutral vectors, isolated fixture regeneration, canonical bytes, fourth-fragment selection invariance and rejection recovery. Its [normative specification](../../../docs/rewrite/PENALTY-TERMS-V1.md) defines term/source containment, endpoint forms, limits, canonical decimals and the no-sentencing boundary. The direct in-process `runLine` path reports an oversized byte string as generic `KDEC001`; the persistent line reader drains an overlong request and reports `KDEC002` before recovering for the next line. Raw malformed JSON may not reveal the fifth fragment before dispatch.

The [supplied-status protocol check](../test/proof_protocol.py) validates all 72 PS fixtures, 111 persistent requests, accepted sixth-fragment requests, every result, proof-neutral vectors, canonical bytes, isolated regeneration and rejection recovery. Its [normative specification](../../../docs/rewrite/SUPPLIED-PROOF-STATUS-V1.md) distinguishes externally assigned classification from technical satisfaction and leaves presumptions, evidence assessment and outcomes outside the kernel. As in earlier variants, malformed JSON before fragment dispatch uses the generic rejection envelope; the stream reader reports an oversized line as `KDEC002`.

The [registered-derivation protocol check](../test/presumption_protocol.py) validates 77 RD requests, 112 persistent requests, both seventh-variant schemas, proof-neutral vectors, complete route traces, fixture regeneration and canonical bytes. Its [normative specification](../../../docs/rewrite/REGISTERED-PRESUMPTION-DERIVATIONS-V1.md) separates supplied status from effective support and reserves legal authority, burden shifting and outcomes for later review.
