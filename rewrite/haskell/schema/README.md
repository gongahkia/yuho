# Production KernelInput/Result v1 schemas

[request.schema.json](request.schema.json) and [result.schema.json](result.schema.json) are closed JSON Schema Draft 2020-12 discriminated unions for `ClosedBooleanBranches-v1` and `AcyclicGuardedExceptions-v1`. They do not alter the frozen language-spike schemas or Canonical IR v1.2. The Boolean wire response still matches its original golden bytes.

Schema validation checks wire shape, constructors, field closure and primitive types. It cannot prove globally unique IDs, total facts, resolved targets, UTF-8 source/span consistency, real calendar dates, whole-registry acyclicity, resource-safe stream handling or semantic trace agreement. The Haskell decoder and validator perform those checks before evaluation. The exception result has separate rule, branch, defeat-reason and dependency observations; no Boolean result field is overloaded. Facts and diagnostic parameters are the only dynamic-key maps.

Run the [exception protocol check](../test/exception_protocol.py) with the pinned Haskell executable to validate positive requests and every result, including rejections. Invalid requests are intentionally *not* all schema-valid: structural failures are expected to fail the schema, while missing references and cycles can be well-shaped and still fail Haskell model validation. The [normative fragment specification](../../../docs/rewrite/ACYCLIC-GUARDED-EXCEPTIONS-V1.md) defines the semantic layer.
