# Production KernelInput/Result v1 schemas

[request.schema.json](request.schema.json) and [result.schema.json](result.schema.json) are closed JSON Schema Draft 2020-12 discriminated unions for `ClosedBooleanBranches-v1`, `AcyclicGuardedExceptions-v1`, `TypedBooleanFacts-v1`, `GuardedPenaltySelection-v1` and `PenaltyTerms-v1`. They do not alter the frozen language-spike schemas or Canonical IR v1.2. The previous four wire response variants retain their original bytes.

Schema validation checks wire shape, constructors, field closure and primitive types. It cannot prove globally unique IDs, total facts, resolved targets, UTF-8 source/span consistency, real calendar dates, whole-registry acyclicity, expanded occurrence limits, resource-safe stream handling, source-contained term spans, numeric order or semantic trace agreement. The Haskell decoder and validator perform those checks before evaluation. The typed result adds ordered fact observations and `KINV007` binding rejection; the fourth result adds selected declaration IDs, ordered supports, per-branch selection trace and `KSEL001` warnings; the fifth adds canonical validated term trees only to selected records. Earlier result variants remain unchanged. Facts and diagnostic parameters are the only dynamic-key maps.

Run the [exception protocol check](../test/exception_protocol.py) with the pinned Haskell executable to validate positive requests and every result, including rejections. Invalid requests are intentionally *not* all schema-valid: structural failures are expected to fail the schema, while missing references and cycles can be well-shaped and still fail Haskell model validation. The [normative fragment specification](../../../docs/rewrite/ACYCLIC-GUARDED-EXCEPTIONS-V1.md) defines the semantic layer.

The [typed protocol check](../test/typed_protocol.py) validates the new discriminated request/result shape, 53 synthetic fixtures, ordered observations and persistent rejection recovery. Its [normative specification](../../../docs/rewrite/TYPED-BOOLEAN-FACTS-V1.md) distinguishes Boolean leaf bindings, annotation checks and descriptive provenance from proof status.

The [penalty protocol check](../test/penalty_protocol.py) validates the fourth request/result shape, 49 synthetic GP fixtures, 76 persistent requests, proof-neutral vectors, the 4,096-occurrence boundary, canonical bytes and rejection recovery. Its [normative specification](../../../docs/rewrite/GUARDED-PENALTY-SELECTION-V1.md) defines exact trace-based guard scope, candidate ID selection and path-specific overlap warnings. Raw malformed JSON may not reveal a fragment before dispatch and retains the generic pre-dispatch rejection envelope.

The [term protocol check](../test/terms_protocol.py) validates the fifth closed shape, all 68 PT fixtures, 110 persistent requests, complete result schemas, proof-neutral vectors, isolated fixture regeneration, canonical bytes, fourth-fragment selection invariance and rejection recovery. Its [normative specification](../../../docs/rewrite/PENALTY-TERMS-V1.md) defines term/source containment, endpoint forms, limits, canonical decimals and the no-sentencing boundary. The direct in-process `runLine` path reports an oversized byte string as generic `KDEC001`; the persistent line reader drains an overlong request and reports `KDEC002` before recovering for the next line. Raw malformed JSON may not reveal the fifth fragment before dispatch.
